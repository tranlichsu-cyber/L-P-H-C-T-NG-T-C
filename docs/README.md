# Mục lục tài liệu

Tài liệu được phân nhóm bên dưới. Các lệnh và đường dẫn mã nguồn trong tài liệu được hiểu là chạy từ thư mục gốc repository, trừ khi có ghi chú khác.

Các báo cáo có ngày và tài liệu phiên bản cũ được giữ làm lịch sử; hướng dẫn hiện hành cần đối chiếu với tính năng trên website. Hai tài liệu sơ đồ tư duy là hồ sơ lịch sử của tính năng đã được gỡ.

## File kích hoạt CI

Chín file `*_TRIGGER.txt` ở thư mục gốc là cấu hình vận hành được các workflow tham chiếu trực tiếp. Chúng được giữ nguyên vị trí và nội dung trong đợt sắp xếp tài liệu này. Di chuyển hoặc sửa các file đó có thể kích hoạt lại triển khai, sửa nội dung hoặc cập nhật dữ liệu lịch sử.

Xem cấu hình tại [`.github/workflows/`](../.github/workflows/). Tài liệu và giấy phép gắn với tài nguyên bản đồ tiếp tục nằm cùng tài nguyên trong [`public/maps/`](../public/maps/).
