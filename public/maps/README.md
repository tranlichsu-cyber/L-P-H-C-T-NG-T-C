# Thái Nguyên: 92 vùng tương tác

Source: https://github.com/BinCry/VN-Database/tree/master/json/geojson/19_thai_nguyen
Dataset export: 2026-07-25; downloaded: 2026-10-13. License: MIT (LICENSE-VN-Database.txt).
92 units: 77 communes, 15 wards. All 25 communes in the existing heritage catalog match.

Coordinates projected using local equirectangular projection at mean latitude, then rounded to 0.1 SVG unit and simplified with maximum 0.3 SVG-unit tolerance. Region topology and holes retained. This is an educational visualization, not a cadastral or legally authoritative boundary service.

Original coordinates remain obtainable from source GeoJSON. Official reference: https://sapnhap.bando.com.vn/
